# سجل عمليات إدخال قراءات العدادات

التصميم المعتمد:
- لكل إدخال جماعي عملية مستقلة برقم وتاريخ ومستخدم.
- Excel واللصق والإدخال الجماعي يمكن تتبعها.
- العملية تحتوي على الإجمالي والمقبول والمرفوض والحالة.
- لكل عملية سجل أحداث غير قابل للتحرير من الواجهة.
- التراجع عن عملية جماعية يجب أن يحذف فقط القراءات المرتبطة بها، وليس أي قراءات سابقة أو من عمليات أخرى.
- المستخدم يربط مستقبلاً بواسطة created_by_id وrolled_back_by_id مع وحدة إدارة المستخدمين.
- يجب أن تمر عمليات Excel عبر المعاينة والفحص قبل الحفظ، ولا تحفظ الصفوف غير الصالحة.
